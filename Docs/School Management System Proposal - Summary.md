## Core Modules

| # | Module | Key Features |
|---|--------|--------------|
| 1 | **Student Management** | Registration, admissions, profiles, transfers, CBC curriculum (PG to G12) |
| 2 | **Fee Management** | Fee structures, billing, tracking, statements, waivers & discounts |
| 3 | **M-Pesa Integration** | Auto-reconciliation, payment receipts, real-time posting |
| 4 | **Academic Management** | Exams, grading, report cards, transcripts, performance tracking |
| 5 | **Attendance Management** | Daily attendance, absence alerts, weekly summaries |
| 6 | **HR & Staff Management** | Employee records, leave management, payroll integration |
| 7 | **Financial Management** | Full BC integration (G/L, AR/AP, budgets, procurement, fixed assets) |
| 8 | **Executive Dashboard** | Real-time KPIs, analytics, drill-down reports |
| 9 | **Parent Mobile App** | iOS & Android — view grades, pay fees, receive notifications |
| 10 | **SMS Gateway** | Automated alerts for fees, attendance, results, announcements |
| 11 | **Reports & Compliance** | Government reports, custom reports, data export |
